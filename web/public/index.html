ℹ️ How Automated Cloud Backup Works:

Every time you log, edit, or import a trade, the system automatically commits your updated ledger directly to your GitHub repository in the background. When Render spins down or restarts, it re-fetches the latest trades from GitHub so you never lose a single trade.

🔑 Enable Auto-Sync on Render in 2 Minutes:

  1. Generate a GitHub Personal Access Token (Classic with repo scope, or Fine-grained with Read/Write for Contents).
  2. Go to your Render Dashboard → Your Web Service → Environment tab.
  3. Click Add Environment Variable: Key: GITHUB_TOKEN, Value: (your GitHub token).
  4. Click Save Changes. Render will automatically enable cloud backup sync!
